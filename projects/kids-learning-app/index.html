Overview

A platform that turns a short prompt from a parent or teacher into a finished, illustrated children's book — written, illustrated, narrated and ready to print. I worked across the whole surface of it: the frontend, the AI generation workflows, backend integrations, authentication, billing, PDF export, multilingual support, SEO, and the Creator Studio where authors edit what the model produced.

My Role

I took over an existing codebase that did not work and led it to a shipping platform in five months. That meant owning the generation pipeline end to end rather than a single layer — prompt design and model selection at one end, Stripe invoices and print fulfilment at the other.

The Generation Pipeline

Turning one prompt into a finished book is not a single model call. It runs as 13 distinct phases, each with its own inputs, failure modes and retry behaviour, so a failure late in the run does not discard the work already done:

  1. Interpret the prompt into a story brief — age band, theme, reading level, language.
  2. Generate the narrative outline and page breaks.
  3. Draft the per-page story text against that outline.
  4. Build the character sheet — the canonical description every illustration must match.
  5. Derive per-page illustration prompts from the text and the character sheet.
  6. Generate illustrations with Gemini image models.
  7. Check each illustration for character consistency and regenerate the ones that drift.
  8. Compose page layouts, placing text against art.
  9. Generate the cover.
  10. Translate for multilingual editions.
  11. Narrate with ElevenLabs — text-to-speech or the author’s own cloned voice.
  12. Assemble the audiobook and stitch it to the page timings.
  13. Export the print-ready PDF for Lulu print-on-demand fulfilment.

Credits are consumed per phase rather than per book, which is what makes a partial failure recoverable without charging the customer twice for the same work.

Challenges & Solutions

The problems that shaped the build, and what I did about them.

Challenge

Diffusion models redraw a character differently on every call, so a book's protagonist changed face from page to page — the single most visible quality failure in the product.

Solution: Built a character-consistency workflow that conditions each illustration on a locked reference for that character, so the same protagonist carries across all pages of a book.

Challenge

Book generation is long-running and multi-stage, but a browser request cannot stay open for it, and a failure at stage 11 must not discard the first ten stages of work.

Solution: Moved generation into a staged pipeline on Supabase Edge Functions with durable per-stage state, so work resumes from the last completed stage instead of restarting.

Challenge

Three payment models — subscriptions, one-time purchases and credit top-ups — all had to draw down against the same generation features without double-charging.

Solution: Designed a single credit ledger as the one place generation cost is accounted for, with Stripe events feeding it rather than each feature reasoning about billing independently.
